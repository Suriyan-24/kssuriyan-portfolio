# Suriyan K.S. — Portfolio

Multi-page static portfolio for GitHub Pages/Vercel.

## Pages
- `index.html` — highlights / home
- `projects.html` — project tiles and source links
- `experience.html` — internships, campus leadership and education
- `posts.html` — curated LinkedIn themes linking to the original profile/activity
- `certifications.html` — CV-listed credentials grouped by topic

## Deploy on Vercel
Import this repository and keep the project root as `./`. It is a static HTML/CSS/JS site and requires no build command or environment variables.

## Content integrity
Project links point to known GitHub repositories or the profile/repository list when a dedicated public source URL was not available. A working public demo is not claimed unless its URL is verified. LinkedIn post cards are thematic until exact post URLs are supplied. Certification verification links should be added from the original credential pages.
